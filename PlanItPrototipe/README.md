# PlanItPrototipe

Prototipo mobile de la app Planit.

## Cómo correr

```bash
cd PlanItPrototipe
npm install
npm run dev
```

Abrí http://localhost:5173 en el browser.

## Pantallas

- `/` — Login / Bienvenida
- `/home` — Home (Próximas Juntadas)
- `/create` — Crear nueva juntada
- `/plan` — Detalle de juntada (Pizza en lo de Coti)
- `/explore` — Explorar planes
- `/profile` — Perfil de usuario

## Flujo

Login → Entrar → Home → Nueva Juntada → CreatePlan → Crear Juntada → Home
Home → click en card → PlanDetail
BottomNav → navega entre Home, Explorar, Crear, Perfil
